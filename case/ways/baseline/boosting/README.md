# TF-IDF и CatBoost

CatBoost получает TF-IDF словесных 1–2-грамм и символьных 3–4-грамм, длину сообщения и число слов. Обучение использует 80% AR-12 train. На оставшихся 20% подбирается порог вероятности класса `1` с FPR ≤ 5%. Сообщение блокируется, если вероятность класса `1` строго выше порога. Разбиение стратифицировано по метке и воспроизводимо с seed 42.

[Общие команды обучения, инференса и оценки](../README.md) для кандидата `boosting`.

Для исполнения нужны `solve.py`, созданный обучением `catboost-proba.joblib` и зависимости группы `boosting` в образе runner. Загружайте только доверенный артефакт Joblib. Решатель читает JSON с полем `input` и возвращает `{"answer":"0"}` или `{"answer":"1"}`. Приведённая оценка на train нужна для локальной проверки.
