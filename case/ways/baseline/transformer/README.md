# Маленький трансформер с ONNX INT8

Однослойный трансформер обучается с нуля на AR-12 train. Он кодирует первые 127 байт UTF-8, добавляет токен классификации и использует маску дополнения до 128 позиций. Экспорт в ONNX использует динамическое INT8-квантование матричных операций с весами. Порог с FPR ≤ 5% подбирается по выходам квантованной модели на стратифицированных 20% AR-12 train, выделенных перед обучением с seed 42.

[Общие команды обучения, инференса и оценки](../README.md) для кандидата `transformer`.

Для исполнения нужны `solve.py`, созданные обучением `model.onnx` и `model.json`, NumPy и ONNX Runtime в образе runner. Решатель читает JSON с полем `input` и возвращает `{"answer":"0"}` или `{"answer":"1"}`. Приведённая оценка на train нужна для локальной проверки.

[Документация экспорта PyTorch](https://docs.pytorch.org/docs/stable/onnx.html)
