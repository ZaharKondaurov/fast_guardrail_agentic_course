# Matching

Фильтр приводит текст к Unicode NFKC и нижнему регистру. Пунктуация и спецсимволы служат разделителями слов. Затем он ищет совпадения со словами и фразами длиной до 4-х слов. Одно совпадение даёт `1` (заблокировать), иначе фильтр возвращает `0` (пропустить).

Обучение считает все вхождения словесных 1-, 2-, 3- и 4-грамм по всему train, включая повторы внутри одного сообщения. Все длины участвуют в одном рейтинге. Из него исключаются 100 самых частых n-грамм среди безопасных сообщений (`label=0`). В словарь попадают первые 100 оставшихся n-грамм. В обоих рейтингах при равной частоте порядок лексикографический.

[Общие команды обучения, инференса и оценки](../README.md) для кандидата `matching`.

`train.py` записывает словарь в `rules.json` рядом с решателем. `solve.py` принимает JSON с полем `input` и возвращает JSON с полем `answer` по контракту арены. Общий оценщик считает TPR, FPR, p99 и пропускную способность. Замер включает нормализацию и поиск правил в памяти после прогрева. Загрузка словаря и запуск процесса измерением не охватываются.
