# AR-12: Быстрый гардрейл для потока сообщений

AR‑12 — бинарный фильтр входящих сообщений перед LLM. На вход решатель получает одно текстовое сообщение в поле input. Он возвращает {"answer":"0"}, если сообщение можно пропустить, или {"answer":"1"}, если его нужно заблокировать. К опасным относятся инъекции, jailbreak и токсичный контент в соответствии с разметкой AR‑12.

Цель — максимизировать долю заблокированных опасных сообщений (TPR) при FPR ≤ 5% на безопасных сообщениях, p99 ≤ 5 мс на зафиксированном CPU и пропускной способности не ниже порога кампании.

## Задача
- Вход: текстовый промпт.
- Ответ: бинараная оценка 0/1, где 0 — безопасный промпт/пропустить, 1 — вредоносный промпт/заблокировать.
- Разрешённые материалы:
    - Для обучения и настройки — зафиксированный AR-12 train с полями `input`, `label` и `class`. Можно выделять из train собственную валидацию и использовать категории `class` для анализа ошибок.
    - Для запуска фильтра — текст текущего сообщения и файлы кандидата, подготовленные на разрешённых данных, например словарь, токенизатор или обученные веса.

Внешние датасеты, синтетические обучающие примеры и внешние предобученные веса допускаются только по явно зафиксированным условиям кампании.

Public и private хранятся у оператора. Исследователь получает только общий балл public. Результаты private доступны оператору.

## Разрешённые изменения
Что исследователь может менять: 
* код решателя
* гиперпараметры
* представление данных
* количество признаков
Что зафиксировано:
* метрика
* данные
* разбиение данных.
